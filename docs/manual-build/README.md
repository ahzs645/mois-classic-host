# Manual build notes (2026-09-28)

The MOIS User Manual v3 (524 articles) was checked against the MOIS tutorials in
`manual-coverage-2026-09-28.csv`, which gives each article a status of covered,
partial, gap or n/a.

The `build-*.md` files are the handoff for the interface built for the gap and
partial articles, one file per area. Each file lists, per manual article:

- what was built: files, window ids, tree nodes and menu items;
- what was left out;
- what is INFERRED, where no manual capture existed;
- the anchor and window ids a tutorial for that article would use.

Tutorials for these articles have not been written yet.
Out of scope for now: the encounter and dynamic forms (Asthma, CHF, COPD,
Diabetes, HTN, Hep C, OA and RA follow-up, First Assessment).
